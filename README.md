# MRL.AI

Responde comentários do Instagram na hora e abre a conversa no Direct.

**Como funciona**
1. Seu cliente comenta uma palavra-chave no post.
2. O MRL.AI responde o comentário publicamente.
3. Em seguida manda a mensagem no Direct, e a conversa passa a ser sua.

**Detalhes**
- Entende maiúsculas, acentos e erros de digitação
- IA para personalizar as mensagens
- Painel de leads e aviso por e-mail
- Sem programar
- Planos a partir de R$ 39,90, pagamento único, sem mensalidade
